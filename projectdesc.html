weather-app

A simple and user-friendly weather application that provides real-time weather updates for any location. Built using HTML, CSS, and JavaScript, this app fetches data from the OpenWeatherMap API to display:

🌡️ Current temperature and weather conditions
📍 Location-based forecasts using geolocation
🌥️ Weather icons for better visualization
⏱️ Auto-refresh and manual search functionality
💾 Local storage to remember last searched location

portfolio

The Portfolio Website is a personal web application designed to showcase a developer’s skills, projects, education, and contact information in a professional and visually appealing format. It is fully responsive, ensuring a seamless experience across devices from desktop to mobile.

🏠 Home/Hero Section – Highlights your name, role (e.g., Front-End Developer), and a call-to-action button.
🧠 Skills Section – Lists technical and soft skills with progress bars or badges.
🧰 Projects Section – Displays portfolio projects like To-Do List, Weather App, Blog UI, etc., with descriptions and links.
🎓 Education Section – Academic qualifications in a timeline or card format.
📞 Contact Section – Contact form with name, email, and message input; optionally connected to email service.
🌙 Dark Theme – Optional aesthetic theme using dark colors for modern UI.
